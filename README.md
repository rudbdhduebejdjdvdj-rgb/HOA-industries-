# HOA Industries — Corporate Website

Bilingual corporate website for HOA Industries, built with plain HTML, CSS and JavaScript.

## Features
- Spanish / English language switch
- Responsive desktop and mobile layouts
- Sections for company overview, capabilities, projects, approach and contact
- Lightweight interactions and reduced-motion support
- No build step or framework required

## Run locally
Open `index.html` in a browser, or serve the folder with any static HTTP server.

## Deploy with GitHub Pages
1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch `main` and folder `/ (root)`.
4. Save and wait for GitHub Pages to publish.

The site is designed to be hosted at the repository root.
